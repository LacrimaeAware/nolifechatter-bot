# Provenance

NoLifeChatter contains a Twitch bot, offline archive tools and optional
persona experiments. The sample logs in `examples/` are synthetic.

The code is available under the [MIT license](LICENSE). Python dependencies
are listed in `requirements.txt`; optional model and training dependencies
are described in [Fine-tuning](docs/FINE_TUNING.md). Those projects retain
their own licenses. No model weights or chat datasets are included.
