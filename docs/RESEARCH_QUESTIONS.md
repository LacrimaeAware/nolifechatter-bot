# Analysis readouts

Authorship scores are classifier assignments to archive authors. Embedding
similarity compares vectors pooled from a chatter's messages. Trait scores
project message or person vectors onto text-defined scales. The included
messages and channels determine these readouts.

The [architecture guide](ARCHITECTURE.md#analysis-data-files) describes the
message index, person vectors and their commands.
